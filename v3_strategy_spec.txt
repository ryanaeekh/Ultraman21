## Layer 4 — Indicators
Status: LOCKED 2026-04-18 (provisional pending firsthand reading deepening of Layer 2 sources)

### Decision

**Component A — Trend signal generator: Volatility-Adjusted Momentum (Moskowitz canonical signal).**

Signal calculation per instrument per 4-hour bar:
- Compute past-N-bar log return
- Compute past-N-bar realized volatility (standard deviation of log returns)
- Signal value = past-N return / past-N volatility
- Long if signal > 0; Short if signal < 0
- Threshold dead-zone around 0 deferred to Layer 5

**Component B — Regime filter: NONE.**

No filter applied. Every signal is taken. Diversification across the 5-instrument panel is the literature-aligned defense against chop, not a regime filter.

**Lookback period N: BLENDED.**

Three parallel signal computations averaged:
- N1 = 180 bars (~30 days) — short trend horizon
- N2 = 540 bars (~90 days) — medium trend horizon
- N3 = 1,440 bars (~240 days / ~8 months) — long trend horizon

Final signal = (signal_N1 + signal_N2 + signal_N3) / 3

Long if blended signal > 0, Short if < 0.

### Justification

1. **Vol-adjusted momentum is the seminal Tier A signal definition** (Moskowitz/Ooi/Pedersen 2012 *Journal of Financial Economics* "Time Series Momentum"). It is the most directly literature-supported single-signal trend implementation available. Vol-adjustment makes signal magnitude comparable across heterogeneous instruments (BTC's signal and DOGE's signal are on the same scale), which is essential for the 5-instrument panel.

2. **No filter is the literature-aligned choice** (Hurst/Ooi/Pedersen "A Century of Evidence on Trend-Following Investing" — AQR 2017 — Tier A). The AQR team running $130B+ in trend strategies does not filter for regime. Their answer to chop is panel diversification. v2's ADX filter contributed to BTC/SOL OVERFIT classification by adding a parameter that worked in periods 1-5 and failed in period 6.

3. **Blended lookback is the literature-aligned parameter choice** (Hurst/Ooi/Pedersen). They use a 1m/3m/12m blend specifically to reduce single-lookback parameter sensitivity. Translating to 4-hour bars: 180/540/1440 bars maps to roughly 30/90/240 days, the same proportional structure.

4. **Single trend signal, no confluence** — enforced by Layer 2 hybrid lock-out. v1's 21-point confluence pattern is rejected. Vol-adjusted momentum alone generates direction; nothing else gates or modifies that direction.

5. **Departure from v2 acknowledged.** v2 used MA-cross + ADX filter. v3 uses vol-adjusted momentum + no filter. This is a deliberate upgrade to the canonical Tier A signal definition, accepting loss of v2 operational familiarity in exchange for stronger evidence base. ADX is consciously abandoned; future v1/v2 nostalgia attempts to reintroduce ADX are rejected by reference to this lock.

Component B (no filter): **Reasoned.** Trader explicitly chose the literature-aligned no-filter position over v2's ADX continuity. This is the harder psychological choice and was made consciously.

## Layer 5 — Entry/Exit Logic
Status: LOCKED 2026-04-18 (provisional pending firsthand reading deepening of Layer 2 sources)

### Decision

**Entry trigger (5.1):** Dead-zone threshold at 0.25 standard deviations of the historical signal distribution.
- Long entry: blended signal > +0.25 × signal_SD
- Short entry: blended signal < -0.25 × signal_SD
- Flat (no entry, no exit if currently in position): -0.25 × signal_SD ≤ blended signal ≤ +0.25 × signal_SD

The signal_SD is computed as the rolling 1,440-bar standard deviation of the blended signal value, refreshed each bar.

**Exit logic (5.2):** Signal-flip exit only.
- Long position closed when blended signal crosses below -0.25 × signal_SD (full reverse to short threshold)
- Short position closed when blended signal crosses above +0.25 × signal_SD
- Position immediately reversed (close + open opposite direction) on full signal flip
- No take-profit, no time stop, no trailing stop
- Winners may give back 30-50% of peak favorable excursion before exit; this is structural

**Stop loss (5.3):** Hard stop at 3 × ATR(240) from entry price.
- ATR computed on 240-bar (~40-day) lookback at 4-hour timeframe
- Long stop: entry_price - 3 × ATR
- Short stop: entry_price + 3 × ATR
- Stop is fixed at entry, does NOT trail
- Stop fires immediately on intra-bar touch (NautilusTrader stop-market order)
- If stop fires, position closes and remains flat until next signal entry per 5.1

### Justification

1. **Dead-zone (5.1) is principled noise defense for 4-hour signals.** Moskowitz/Ooi/Pedersen do not use a dead-zone at monthly timeframes (Tier A). At 4-hour timeframes, signal-to-noise is worse and near-zero signals fire whipsaw entries during regime transitions. 0.25 SD is a standard practitioner threshold (Carver "Systematic Trading" Tier B; common in AQR practitioner notes), single parameter, low curve-fitting surface. The threshold scales with the signal's own volatility, so it adapts across instruments without per-instrument tuning.

2. **Signal-flip-only exit (5.2) is literature-aligned.** Hurst/Ooi/Pedersen and Moskowitz et al. exit on signal reversal; they do not use take-profits or trailing stops. The AQR paper specifically documents that trailing stops reduce returns more than they reduce drawdown — the mechanism is that trailing stops convert giving-back-profit (uncomfortable but recoverable on next trend) into realized loss (locked-in suboptimal exit). The blended 180/540/1440 signal naturally requires multi-horizon trend reversal to flip, so signal-flip IS a robust trend-reversal exit, not arbitrary.

3. **Hard stop at 3×ATR (5.3) is a deviation from pure literature, justified by perp substrate.** AQR's commodity futures portfolios run unlevered or low-levered with no auto-liquidation risk; they hold through arbitrary drawdowns until signal flip. v3 runs Binance USDT-M perp at up to 5x leverage on a $14.8k account, where a ~20% adverse move triggers exchange liquidation regardless of strategy logic. The 3×ATR(240) stop caps single-trade loss at approximately 6-9% of position notional in normal volatility regimes, well below liquidation distance, while leaving room for normal noise. The stop protects against substrate failure (forced liquidation), not against signal failure. 3×ATR is the Turtle system's stop distance (Faith Way of the Turtle, Tier B) and a managed-futures practitioner standard.

### Decision-quality disclosure

5.1 (dead-zone 0.25 SD): **Reasoned.** Trader correctly identified the threshold as based on signal volatility and accepted the noise-defense justification.

5.2 (signal-flip exit only): **Reasoned, with stronger justification than literature.** Trader cited perp-specific stop-hunting / liquidity-hunt failure mode for trailing stops, drawn from ~3 years BTC perp trading experience. This is firsthand operational reasoning that strengthens the literature case for not using trailing stops on crypto perp specifically.

## Layer 6 — Risk and Sizing
Status: LOCKED 2026-04-18 (provisional pending firsthand reading deepening of Layer 2 sources)

### Decision

**Sizing methodology (6.1):** Volatility targeting at 15% annualized per-position vol target.

Position size calculation per instrument per entry:
- instrument_vol_annualized = realized_volatility(returns, lookback=240 bars) × sqrt(2190)
  (where 2190 = 4-hour bars per year: 365 × 24 / 4)
- target_notional = (0.15 / instrument_vol_annualized) × account_equity
- position_size = target_notional / instrument_price
- Margin required = target_notional / leverage = target_notional / 5

If multiple positions open simultaneously, target_notional is computed from current account equity at entry time (not equity at strategy start). Equity reflects realized PnL from closed trades plus unrealized PnL from open positions.

**Leverage (6.2):** Uniform 5x leverage across all 5 instruments.

Set via Binance USDT-M futures leverage parameter at venue setup. Same leverage applies to all instruments regardless of vol or signal strength. Per-instrument size differentiation is handled by vol-targeting in 6.1, not by leverage.

**Concurrent position cap (6.3):** Cap at 5 (all 5 instruments may hold positions concurrently).

No selection rule applied if more than 3 instruments fire signals simultaneously. All firing signals are taken, sized per 6.1.

### Justification

1. **Vol-targeting (6.1) is the canonical Tier A sizing method for trend-following** (Moskowitz/Ooi/Pedersen 2012 JFE; Hurst/Ooi/Pedersen). The methodology equalizes vol contribution across heterogeneous instruments — DOGE's natural high vol does not dominate portfolio risk because its position size is automatically reduced. 15% per-position target is a conservative practitioner value (institutional managed-futures typically targets 10-20% per position; 15% is the middle of that range).

2. **Vol-targeting fits trend-following's return distribution structure**, where edge comes from fat-tail winners rather than win rate. Fixed-fractional R-based sizing (the "1-2% per trade" rule from Van Tharp / Turtles) is designed for discretionary traders thinking in R:R terms with independent trades; it caps winner upside in ways that strip trend-following's structural edge. Vol-targeting plus the Layer 5 hard stop (3×ATR) produces approximately 1.5% per-trade dollar-risk as a side effect, while correctly handling portfolio-level vol contribution that the 1-2% rule does not.

3. **Uniform 5x leverage (6.2)** avoids redundant per-instrument adjustment. Vol-targeting in 6.1 already produces per-instrument size differentiation; vol-scaled leverage would double-count, introducing an extra parameter and reducing backtest-to-live auditability. 5x is conservative for crypto perp (Binance allows up to 25-50x on most instruments); leaves margin headroom before liquidation. Combined with 3×ATR hard stop, single-trade liquidation risk is structurally bounded.

4. **Concurrent cap of 5 (6.3)** is consistent with vol-targeting bounding portfolio vol independently of position count. With 5 positions at 15% per-position vol target and assuming 0.5-0.8 average correlation across crypto instruments, expected portfolio vol is approximately 25-30% annualized (lower than 5 × 15% = 75% naive sum due to correlation). This is within standard managed-futures portfolio vol ranges. Capping at fewer positions (e.g., 3) without principled selection rule throws away diversification benefit. Layer 1 noted operational ceiling of 3-5 manageable positions; vol-targeting keeps individual position sizes small enough that 5 concurrent remains operationally viable per trader's confirmation.

## Layer 7 — Walk-Forward Gates
Status: LOCKED 2026-04-18 (provisional pending firsthand reading deepening of Layer 2 sources)

### Decision

**Walk-forward window structure (7.1):** Rolling window.
- Train window: 24 months (~4,380 4-hour bars)
- Test window: 5 months (~915 4-hour bars)
- Total periods: 6 (rolling forward in 5-month increments)
- Total span: 24 months train + (5 × 6) months test = 54 months from first signal availability
- First signal date: ~January 2022 (DOGE launch May 2021 + 8-month warm-up)
- Walk-forward span: ~Jan 2022 - July 2026 (extends past current date; partial Period 6 acceptable)

**Per-instrument classification gates (7.2):** v2 carryover, PF-based.
- ROBUST: Profit Factor > 1.3 in ≥4 of 6 periods AND no period with PF < 0.7
- MARGINAL: Profit Factor > 1.0 in ≥4 of 6 periods AND no period with PF < 0.5
- OVERFIT: Any other case where INSUFFICIENT_SAMPLE does not apply
- INSUFFICIENT_SAMPLE: <30 trades in any single test period

**Portfolio-level acceptance bundle (7.3):** Strict bundle. ALL three gates must pass to authorize live capital.
- Gate A: Portfolio Sharpe ≥ 0.5 across the full 30-month aggregated test window
- Gate B: Maximum drawdown ≤ 35% across the full 30-month aggregated test window
- Gate C: ≥3 of 5 instruments classify as ROBUST or MARGINAL per 7.2

**Paper trading validation (7.4):** 90 days minimum, OR 30 paper trades minimum, whichever is longer.
- Acceptance: paper trading P&L must match backtest run on the same calendar period within ±20% (slippage and execution variance acceptable; >20% divergence indicates substrate bug)
- Bug found in paper trading: fix substrate, re-run paper trading from day zero, do NOT modify Layer 1-6 spec
- Paper trading divergence with no identifiable bug: v3 does not ship; reopen substrate investigation

### Justification

1. **Rolling window (7.1) is regime-robust** for trend-following on crypto where regimes shift dramatically (2022 LUNA/FTX bear, 2023 chop, 2024 ETF bull, etc.). Expanding window dilutes recent regimes with old data; rolling forces validation that the strategy works in *recent* regimes specifically. v2's BTC/SOL OVERFIT classification was driven by Period 6 (2025+) failure under expanding window — exactly what rolling would have flagged earlier in development.

2. **PF-based classification (7.2)** carried from v2 methodology unchanged. Profit factor is less sensitive to outlier trades than Sharpe ratio (a single fat-tail winner doesn't inflate PF the way it inflates Sharpe). For trend-following with structurally fat-tailed return distributions, PF is the more robust per-period metric. v2's classification thresholds (PF > 1.3 for ROBUST, PF > 1.0 for MARGINAL) are literature-honest gates derived from managed-futures practitioner standards. Keeping v2 thresholds preserves direct comparability between v2 and v3 classification results.

3. **Strict bundle (7.3)** corrects the v2 mistake of treating 1-of-3 ROBUST as panel validation. ≥3 of 5 instruments must validate to demonstrate panel-level edge rather than single-instrument luck. Sharpe ≥0.5 is realistic for retail single-strategy crypto perp implementation (institutional Hurst/Ooi/Pedersen achieves ~1.0 on a fully-diversified 67-market 4-asset-class portfolio; retail single-strategy 5-perp version naturally lower due to costs, correlation, and concentration). DD ≤35% is the upper end of literature-norm trend-following drawdown — anything higher is unshippable for the trader's $14.8k capital base regardless of Sharpe.

4. **90-day OR 30-trade paper trading (7.4)** is gated on trade-count not just calendar time, ensuring sufficient sample to validate execution divergence from backtest. 90 days at 4-hour bars on 5 instruments produces approximately 15-25 trades; the 30-trade floor extends paper trading if signal density is unusually low. ±20% backtest-vs-paper divergence is the bug detection threshold — within this, normal slippage and execution variance is accepted.

### Pre-registration discipline (Layer 7 binding — and meta-binding for all prior layers)

Layer 7 is the layer that ENFORCES discipline on all prior layers. The gates locked here are the criteria that determine whether v3 ships or doesn't ship. They cannot be:

### Constraints to carry forward to implementation

- Walk-forward must use TRUE rolling window — train data does NOT include test data, no overlap, no leakage. NautilusTrader supports this natively via BacktestNode with separate run configs per period.
- Rebalance / signal recomputation happens on every 4-hour bar close within both train and test periods. No "warm-up only on train, then run forever" — each test period is independent of prior test periods for validation purposes (though the strategy state continues to evolve in live trading).
- PF calculation per period uses gross profit / gross loss (Wilder's standard PF). Validate calculation against a hand-checked sample period before trusting any classification result.
- Sharpe calculation uses 4-hour bar returns annualized by sqrt(2190) (matching Layer 6 vol annualization convention). Risk-free rate = 0 (standard for crypto strategies).
- Drawdown calculation is peak-to-trough on the cumulative equity curve, computed at 4-hour bar resolution.
- Paper trading must run on Binance demo (futures testnet merged into demo per Binance integration docs verified at architecture viability check), using the SAME strategy code as the backtest, NOT a separate "paper trading" branch. Backtest-to-live code parity is structural via NautilusTrader and must not be broken.
